# Paragon Photo: notes for agents

Paragon Photo is the owner's personal fork of PhotoCraft (`upstream` remote:
https://github.com/storytold/photocraft). Read this first, then `AGENTS.md` (upstream's guide: the
architecture, the never-crash rules, "everything is a command", the tests) and `docs/`.

## What the fork changes, and how

- **The rebrand is a script, not hand edits.** `scripts/paragon_rebrand.py` renames what a person
  sees or types: the product name (`Paragon Photo` in prose, `ParagonPhoto` in paths and
  identifiers), the binaries (`paragon-photo`, `paragon-photo-cli`), the app id
  (`io.github.aryez.paragonphoto`), the settings folder and the MCP server name. It is idempotent.
  Run it after every upstream merge; `--check` must report 0 changes before committing.
- **Internals keep upstream's names on purpose:** Cargo packages and crates (`photocraft-engine`,
  `photocraft_doc::`), types (`PhotocraftApp`), `PHOTOCRAFT_*` environment variables, log targets.
  Renaming ~30,000 internal references would make every upstream merge conflict. Don't rename them.
- **A line that must name upstream PhotoCraft** (credits, the upstream link) carries a
  `paragon:keep` marker (`// paragon:keep`, `<!-- paragon:keep -->`), which the script skips.
- **Not rebranded:** URLs, `LICENSE*`, `NOTICE`, `ATTRIBUTION.md`, `contributors/`, the `.pcraft`
  format and its MIME type and XMP namespace, and names that live in dependencies
  (`craft::update::suite::PHOTOCRAFT`, the `craft.artcraft` theme id, craft-i18n's
  `photocraft.tsv`, `photocraft-corpus`).
- **Licences:** keep PhotoCraft's copyright in `NOTICE` and every attribution. The Paragon Photo
  name and icon are the owner's, not open source. Never use the ArtCraft name or marks.
- **The icon** is generated by `scripts/paragon_logo.py` (Pillow) from the Paragon PR7 icon's
  geometry; don't edit the files in `assets/app-icon/` by hand.
- **Look:** the Paragon family's OBSIDIAN (default) and AURORA finishes, from the Paragon PR7
  plugins (`Paragon-PR7-D` / `Paragon-PR7-G` `source/ui/Finish.*`, `ParagonLookAndFeel.*`).
- **Web build:** `apps/photocraft-web*` are excluded from the workspace; leave their sources.
- **CI:** upstream's workflows are parked in `.github/upstream-workflows/` (inactive); don't move
  them back without the owner asking.
- **Updates** come only from `ARYEZ/Paragon-Photo` releases (`UPDATE_APP` in
  `crates/ui-egui/src/lib.rs`), never from upstream.

## Building

Rust 1.95+. `cargo build -p photocraft -p photocraft-cli` (the packages keep upstream's names; the
binaries are `paragon-photo` and `paragon-photo-cli`). A full build compiles ~870 crates.

## Syncing upstream

```bash
git fetch upstream
```

```bash
git merge upstream/main
```

```bash
python3 scripts/paragon_rebrand.py
```

Then build and test. On a conflict in a file the script rewrites, take upstream's side for the
conflicting hunk and re-run the script.
